### About Me

I'm a Computer Engineering student who enjoys understanding how complex systems work and then building them from scratch.

I'm particularly interested in **simulation and system design**, creating systems with interacting components, defining their rules, and seeing how simple rules can produce complex behavior.

Some of the areas I enjoy exploring:

* Simulation systems and emergent behavior
* Physics engines and physics simulation
* Evolution and artificial-life simulations
* Machine learning simulations
* Graphics programming and visualization
* Game development

I'm especially interested in designing complex systems, understanding how their components interact and how simple rules can lead to emergent behavior.

I'm currently working toward building more complex simulations.

### Featured Projects

* [Chess](https://github.com/Enginmann/Chess) – Chess built from scratch with legal move generation, turn tracking, check detection, and pawn promotion, with game logic cleanly separated from rendering.

* [OS Scheduler](https://github.com/Enginmann/OS-Scheduler) – Operating system simulation implementing CPU scheduling, process dispatching, preemption, load balancing, paging, page faults, and NRU page replacement using C and Linux IPC.

* [iWannaEat](https://github.com/Enginmann/iWannaEat) – Full-stack food and recipe discovery platform built with Node.js, PostgreSQL, and React, featuring recipes, restaurants, shopping lists, articles, and user interactions.

* [Tetris](https://github.com/Enginmann/Tetris) – Full Tetris clone built with Python, Pygame, and NumPy, featuring progressive difficulty, next-piece preview, shadow projection, and persistent high scores.

* [Maze Generator](https://github.com/Enginmann/Maze-Generator) – Real-time maze generation visualizer using iterative DFS backtracking, C++, SFML, and CMake.

* [Sorting Visualizer](https://github.com/Enginmann/Sorting-Visualizer) – Real-time visualization of sorting algorithms with animated comparisons and swaps using C++, SFML, and CMake.
